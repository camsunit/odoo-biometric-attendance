Key Features

⚡ 1. Real-time Punch Sync
Attendance data is pushed from the device to Odoo HR Attendance the instant a punch occurs — no polling delays, no manual exports, no gaps.
🌐 2. 100% Global Device Compatibility
Every biometric attendance machine that exists in the world is supported — through Native Push for cloud-capable devices and Hybrid Push for legacy or network-restricted hardware. No device is left behind.
🔌 3. Zero Extra Software
No manufacturer software, no ZKTeco ADMS server, no third-party middleware. Communication happens through a secure HTTP API. Connect your device to the internet — punches land in Odoo automatically.
☁️ 4. Offline Punch Synchronization
If a device loses connectivity, punches are stored locally on the device or intermediary service. The moment connectivity is restored, all queued records sync to Odoo automatically — zero data loss guaranteed.
⚙️ 5. Customizable & Scalable
Tailor the integration to your HR workflows. Handles any fleet size — from a single office to enterprise-wide deployments spanning thousands of devices across hundreds of locations globally.
🔑 6. Valid API License Required
Your biometric device must have a valid API license to communicate with this module. Check the API licensing guide to enable it on your device.

How It Works

  1. Check compatibility — Visit developer.camsbiometrics.com to verify your device. Compatible devices use Native Push. Others use Hybrid Push.
  2. Configure your device — Point it to the Cams Biometrics cloud API endpoint. Ensure a valid API license is active on the device.
  3. Install this module — Install in your Odoo instance and link your device credentials.
  4. Go live — Punch data flows into HR Attendance in real time. Offline punches sync automatically on reconnect. No further action needed.
